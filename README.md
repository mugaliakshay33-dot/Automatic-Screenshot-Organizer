# Automatic Screenshot Organizer

## Description

A Python automation project that automatically organizes screenshot and image files into a separate folder.

## Features

* Automatically detects PNG, JPG and JPEG files.
* Creates an organized folder automatically.
* Moves images using Python file handling.
* Counts the number of images organized.

## Technologies Used

* Python
* OS Module
* Shutil Module

## How to Run

1. Install Python.
2. Download the project.
3. Run `screenshot_organizer.py`.
4. Enter the folder path.
5. Your images will be organized automatically.
